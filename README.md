
# SIAPE
### Sistema de Gestión Empresarial para Pymes

SIAPE es una aplicación web de gestión empresarial desarrollada para pequeñas y medianas empresas. Permite administrar inventario, proveedores, clientes, pedidos, facturas, pagos, trabajadores, bodegas y reportes desde una interfaz centralizada.

## Tecnologías utilizadas

**Frontend:** React + Vite  
**Backend:** Node.js + Express  
**Base de datos:** MySQL  
**Autenticación:** JWT + Verificación en dos pasos por correo  
**Servlets:** Java (NetBeans)

## Módulos del sistema

- Autenticación con verificación en dos pasos
- Gestión de Trabajadores
- Gestión de Proveedores
- Gestión de Productos e Inventario
- Gestión de Pedidos a Proveedores
- Gestión de Clientes
- Facturación
- Pagos
- Bodegas
- Reportes
- Perfil del Negocio
- PQRS
